# Studyboard v6 changes

- Group selector moved entirely to Live page.
- Live page shows only members of the active group.
- Group control has Edit / Share / Hide-Show / Switch-Create actions.
- NOW linked-target control is a single round button between timer and Start/Stop.
- Focus button is a round top-right timer control.
- Both controls are hidden in Focus Mode.
- Group edit supports name, targets, deadline, member removal and owner delete.
